# NEXORA Keyboard Full v2.0
Khmer + English Android keyboard with local Room Clipboard Library, pin/favorite/search/delete, file creation with user-selected location, and GitHub Actions APK build.

The clipboard has no artificial item-count cap; actual capacity depends on device storage.

Next production upgrades: full Khmer phonetic/predictive input, Shift/Caps, emoji/symbol picker, additional language packs, complete folder/file browser/editor, import/export backup, themes, and privacy controls.
